Essential Git Commands

1. `git init` - Initializes a new Git repository.
2. `git add` - Stages changes for the next commit.
3. `git commit` - Saves staged changes to the repository.
4. `git branch` - Creates or lists branches.
5. `git merge` - Combines changes from another branch.
6. `git status` - Displays the current state of the working directory.
7. `git clone` - Creates a local copy of a remote repository.
